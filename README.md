# Async ML Service: RuBERT-tiny2 Vectorizer
Асинхронный ML-микросервис для получения векторных представлений (эмбеддингов) текста на русском языке.

В проекте применены следующие паттерны и технологии:

Warm Loading: Модель загружается в память единожды при старте воркера, что полностью устраняет задержку (Cold Start) при первых запросах.
Асинхронная обработка через брокер: Взаимодействие построено на связке FastAPI + Celery + RabbitMQ. HTTP-сервер не занимается тяжелыми вычислениями, а мгновенно делегирует задачи в фоновый процесс.
Docker Compose: Вся инфраструктура (сервер, воркер, брокер сообщений) поднимается одной командой в изолированных контейнерах.

1. Клиент отправляет POST-запрос с текстом на FastAPI (порт 8000).
2. FastAPI не ждет вычислений. Оно создает задачу в Celery и мгновенно кладет её в очередь RabbitMQ. Клиенту возвращается task_id.
3. Celery Worker (отдельный фоновый процесс) постоянно слушает RabbitMQ. Как только появляется задача, он забирает текст.
4. Worker передает текст в ML-модель (которая уже лежит в оперативной памяти благодаря Warm Loading) и получает вектор.
5. Worker сохраняет результат в RabbitMQ (в очередь результатов).
6. Клиент делает GET-запрос по task_id и забирает готовый вектор.
